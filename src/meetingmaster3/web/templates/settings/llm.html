AWS keys for Bedrock

Bedrock backends sign in to AWS with this access key pair. Create it for a separate IAM user that may only call Bedrock; the step-by-step guide is “Setting up AWS Bedrock, step by step” in docs/user-guide/llm-backends.md. Leave both empty to use an AWS profile (the backend's “AWS profile” field) or the standard AWS environment variables instead.
